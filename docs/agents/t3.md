# T3 Stack docs

Canonical documentation for this repo’s stack is **Create T3 App**, not training data or third-party roundups.

Start here: [https://create.t3.gg/en/introduction](https://create.t3.gg/en/introduction)

Use the **App Router** pages (the map assumes App Router, not Pages Router). Read the relevant create.t3.gg page before scaffolding or writing T3 code (tRPC, Prisma, NextAuth.js, folder layout, env).

## Pages to prefer

- [Introduction](https://create.t3.gg/en/introduction)
- [Installation](https://create.t3.gg/en/installation) — `npm create t3-app@latest` (App Router; Prisma + tRPC + NextAuth.js + Tailwind)
- [Folder structure (App)](https://create.t3.gg/en/folder-structure-app)
- Usage: [Prisma](https://create.t3.gg/en/usage/prisma), [tRPC](https://create.t3.gg/en/usage/trpc), [NextAuth.js](https://create.t3.gg/en/usage/next-auth)

T3 docs still say **NextAuth.js**; the map’s “Auth.js Google allowlist” is the same library family. Prisma vs Drizzle: this repo’s stack assumption is **Prisma**, not Drizzle.

Do not copy Alvo Cifras’ Pages Router + `src/utils/api.ts` layout when scaffolding alvo-songs — follow the App Router tree on create.t3.gg.
